# EE

General electrical engineering: circuits, parts, power, and boards. A newcomer can start at any module that is already written. A project may show up as an example or a practical. It is not the subject of the series.

The boundary with the RF series is a 50 Ω trace. Controlled impedance, matching, antennas, link budgets, noise-figure cascades, and radio register maps live under [RF]({{ '/rf/' | relative_url }}).
